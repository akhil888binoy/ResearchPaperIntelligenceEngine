# ResearchPaperEngine

Hybrid-search RAG service over research papers. Ask a question through a FastAPI endpoint and get an answer grounded in the paper text, generated by a local Ollama model.

## How it works

1. **Ingest** – `docs/attentionallyouneed.pdf` is loaded, split into 100-token chunks (50 overlap), embedded with Ollama, and stored in an in-memory Chroma collection at startup.
2. **Rewrite** – the user question is rewritten into a search query by the LLM.
3. **Retrieve** – two retrievers run on the rewritten query:
   - dense: Chroma vector search (top 10, with a distance gate)
   - sparse: BM25 via `bm25s` (top 10)
4. **Fuse** – results are merged with Reciprocal Rank Fusion.
5. **Rerank** – Voyage AI `rerank-2.5` picks the top 3 chunks.
6. **Generate** – Ollama answers using only the reranked context.

```
src/
  ingestion/parser.py        PDF load, chunk, embed, store in Chroma
  retrieval/retrieve.py      query rewrite + vector retrieval
  retrieval/bm25_retrieve.py BM25 retrieval
  reranking/reranker.py      RRF fusion + Voyage rerank
  generation/llm.py          Ollama client + answer generation
  services/rag.py            pipeline orchestration
  routers/research.py        FastAPI router
main.py                      app entrypoint
```

## Requirements

- Python 3.14+ and [uv](https://docs.astral.sh/uv/)
- [Ollama](https://ollama.com) running locally with the `qwen` model pulled
- A [Voyage AI](https://www.voyageai.com) API key

## Setup

```bash
uv sync
ollama pull qwen
```

Create a `.env` file:

```
VOYAGE_API_KEY=your_key
DEBUG=false
```

## Run

```bash
uv run uvicorn main:app --reload
```

Ingestion runs on startup, so the first boot takes a moment.

## API

`POST /api/rag/query?query=<question>`

```bash
curl -X POST "http://localhost:8000/api/rag/query?query=What%20is%20multi-head%20attention"
```

Returns the generated answer as a string. Interactive docs at `http://localhost:8000/docs`.

## Adding papers

Drop a PDF in `docs/` and point `PyPDFLoader` in `src/ingestion/parser.py` at it. Only one paper is indexed at a time for now.
